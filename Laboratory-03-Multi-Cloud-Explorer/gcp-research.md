# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP), also called Google Cloud, is a cloud computing platform that provides infrastructure and services for computing, storage, databases, networking, analytics, artificial intelligence, and application development. Organizations can use Google Cloud to build, deploy, and manage applications and workloads using Google's global infrastructure.

## Global Infrastructure

Google Cloud provides infrastructure through geographic regions and zones. A region is a geographic area that contains multiple zones, while zones are deployment areas within a region. Using multiple zones can help organizations improve the availability and reliability of their applications.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to manage Google Cloud resources and services. Users can create and configure resources, monitor applications, manage projects, and access different Google Cloud services through the console.

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that organizations can use to run applications and workloads in Google Cloud.

### 2. Cloud Storage

Cloud Storage is an object storage service that can store files, backups, media, and other types of data.

### 3. Virtual Private Cloud (VPC)

Google Cloud VPC provides networking capabilities that allow organizations to connect and manage cloud resources in a virtual network.

### 4. Cloud Identity

Cloud Identity provides identity and access management capabilities that help organizations manage users and control access to resources and applications.

## Three Advantages

1. **Strong artificial intelligence and machine learning capabilities** – Google Cloud provides a wide range of AI and machine learning technologies that can support advanced applications and research.

2. **Kubernetes expertise** – Google Cloud provides Google Kubernetes Engine (GKE), a managed Kubernetes service that helps organizations deploy and manage containerized applications.

3. **Global infrastructure** – Google Cloud provides a global network of regions and zones that can support applications serving users in different geographic locations.

## Typical Enterprise Use Cases

Organizations use Google Cloud for web applications, data analytics, artificial intelligence and machine learning, containerized applications, databases, data storage, software development, and large-scale digital services.
