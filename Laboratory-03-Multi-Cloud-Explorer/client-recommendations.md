# Checkpoint 4 – Client Recommendations

## Client A – Startup Company

**Recommended Platform: AWS**

AWS is a suitable choice for a startup because it provides scalable cloud services that can support an application as the company grows. The startup can begin with resources that match its current needs and increase them as demand increases. AWS also provides many services that can help the company build and operate its application.

**Recommended Services:**
- Amazon EC2
- Amazon S3
- Amazon RDS

## Client B – University

**Recommended Platform: Microsoft Azure**

Microsoft Azure is the most appropriate choice because the university already uses Windows Server, Microsoft 365, and Active Directory-related technologies. Azure provides strong integration with Microsoft's ecosystem and supports hybrid cloud environments. This can make the transition to cloud services easier for the university.

**Recommended Services:**
- Azure Virtual Machines
- Microsoft Entra ID
- Azure SQL Database

## Client C – AI Research Company

**Recommended Platform: Google Cloud Platform**

Google Cloud is a strong choice for an AI research company because it provides services for artificial intelligence, machine learning, and high-performance computing. These services can support the development and deployment of AI applications. Google Kubernetes Engine can also be used for containerized workloads.

**Recommended Services:**
- Compute Engine
- Vertex AI
- Google Kubernetes Engine (GKE)

## Client D – Global E-Commerce Company

**Recommended Platform: AWS**

AWS is suitable for a global e-commerce company because it provides scalable and globally distributed cloud infrastructure. Its services can support highly available applications and automatically handle changes in workload. This can help the company serve customers in different parts of the world.

**Recommended Services:**
- Amazon EC2
- Elastic Load Balancing
- Amazon S3
