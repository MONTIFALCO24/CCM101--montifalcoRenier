## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest selections of cloud services among the three major providers. Its services cover computing, storage, databases, networking, security, analytics, artificial intelligence, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. It works closely with products and services such as Windows Server, Microsoft 365, Active Directory-related technologies, and other Microsoft enterprise solutions.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is particularly strong in artificial intelligence, machine learning, and Kubernetes. Its AI services and Google Kubernetes Engine (GKE) provide tools for organizations developing AI applications and containerized workloads.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides a broad range of services and gives organizations many options for different workloads. Its large ecosystem can also provide opportunities to learn different areas of cloud computing and support applications as they grow.
