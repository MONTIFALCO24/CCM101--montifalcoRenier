# AWS Research

 Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides many technology services over the internet. These services include computing, storage, databases, networking, security, analytics, and artificial intelligence. AWS allows organizations to use computing resources without having to maintain all of the physical infrastructure themselves.

 Global Infrastructure

AWS operates its cloud infrastructure in different geographic locations around the world. Its infrastructure is organized into Regions, Availability Zones, Local Zones, and Wavelength Zones. An AWS Region is a separate geographic area, while Availability Zones are isolated locations within a Region. Using multiple Availability Zones can help organizations design applications that remain available even when one location experiences a failure.

Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Through the console, users can search for services, manage cloud resources, view notifications, access CloudShell, and manage account and billing information. Users can also select the AWS Region where they want to manage regional resources.

## Four Core Services

 Amazon EC2

Amazon Elastic Compute Cloud (Amazon EC2) provides virtual servers that organizations can use to run applications and workloads. Users can select different types of computing resources depending on their application requirements.

 Amazon S3

Amazon Simple Storage Service (Amazon S3) is an object storage service. It can be used to store files, backups, application data, media, and other types of digital information.

 Amazon VPC

Amazon Virtual Private Cloud (Amazon VPC) allows organizations to create a logically isolated virtual network in AWS. It provides control over networking components such as subnets, routing, and network connectivity.

 AWS IAM

AWS Identity and Access Management (IAM) helps control access to AWS resources. Organizations can use IAM to manage identities and permissions so that users and applications receive only the access they need.

 Three Advantages

1. Wide range of services – AWS provides many services for computing, storage, databases, networking, security, analytics, and other technology requirements.

2. Scalability – Organizations can increase or decrease cloud resources based on their workload and business requirements.

3. Global infrastructure – AWS provides infrastructure in multiple geographic Regions and Availability Zones, allowing organizations to deploy applications closer to their users and design highly available systems.

Typical Enterprise Use Cases

Enterprises use AWS for many different workloads. Common examples include hosting websites and mobile applications, storing and backing up business data, running databases, developing and deploying software, performing data analytics, and supporting large-scale online services. AWS can also be used for artificial intelligence, machine learning, application migration, and hybrid cloud environments.
